# SALES PERFORMANCE DASHBOARD

## Project Overview

The Sales Performance Dashboard is an Excel-based data analysis project designed to visualize sales performance, identify top customers, and understand sales trends through interactive charts and Pivot Tables.

## Objectives

* Analyze sales performance using Excel.
* Identify top customers based on sales.
* Track sales trends over time.
* Understand regional sales distribution.
* Present key sales insights in a clear and professional format.

## Tools & Technologies

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Bar Chart
* Line Chart
* Pie Chart

## Dashboard Components

1. **Top Customers by Sales** – Displays customer sales performance.
2. **Sales Trend Over Time** – Visualizes changes in sales over time.
3. **Sales Distribution by Region** – Shows how sales are distributed across different regions.

## Key Features

* Interactive Pivot Tables and charts.
* Visual representation of sales data.
* Easy-to-understand sales insights.
* Organized dashboard layout for reporting and analysis.

## How to Use

1. Open the Excel workbook.
2. Navigate to the Dashboard sheet.
3. Review the charts and key sales insights.
4. Use Pivot Table filters to explore different categories or regions, where applicable.
5. Refresh the Pivot Tables if the underlying source data changes.

## Conclusion

This project demonstrates the use of Microsoft Excel for data analysis, visualization, and sales reporting. It helps present sales information in a structured format to support better understanding and decision-making.
